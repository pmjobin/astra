# Enum/error proposed semantics model

Standard-library Python only; no compiler, parser, interpreter, runtime or LLVM
implementation. [The contract](../../../docs/architecture/enums-and-errors.md)
is normative. Model names Decode/Load abbreviate source DecodeError/LoadError;
Owner tokens stand for whole existing buffer responsibility, not native addresses.
Header is a two-integer snapshot. FutureOwnedError tests extension cleanup only;
initial ERROR-1 domains are copyable.

Run from the repository root:

```sh
python3 -B tools/design/enum-error-contract-1/qualify.py --output ~/Workspace/codex/work/astra/runtime/enum-model/model-results.json
```

`model.py` defines transitions and immutable nominal values. `checker.py` never
calls those transitions: it validates active schema, owner uniqueness and an
independent acquisition/transfer/disposal ledger, borrow witnesses, exact lexical
destinations, crossed-scope cleanup on error edges, publication evidence and the
single consuming observer. Its copyability search is a separate iterative
all-variants search rather than the transition's recursive predicate. Schema
data is shared authority; it is not a second implementation of the language
grammar or type system. Expected owner counts are handwritten literals.

`qualify.py` has directed normal/failure/refusal witnesses, eight equivalence
cases and direct state/edge corruption controls. Valid controls are checked
before mutation and restored afterward. No expected trace is generated by
replaying the transition routine. The explicit/concise paths differ in source
disposition but share the actual primitive value/cleanup operations, as the
proposed compiler should. Equivalence checks same Success/Error
policy, values and owner events; one source evaluation is an unexecuted compiler
obligation, explicitly labeled in the results; deliberate wrapping is not equated.

Before exploration, BOUNDS declares two enum cells plus two owner cells/tokens,
three variants, depth-three payloads, depth-two handlers, six transitions and
20,000 states per domain. BFS explores Decode, BufferState and
ArrayResult<u8,Decode>. It includes construction/staging failure, replacement,
copy/move/consume/drop, borrow/end and fresh acquisition; handler/reservation/
retirement behaviors are fixed directed domains, not executor exploration.
The checker runs before deduplication, including each reachable edge. Keys
retain storage epochs, reservations, borrows and owner-event history; read/copy/
binding administrative events are omitted only after their independent check.
Minimal BFS failing traces are raised; successful full traces are not retained.
State cap hits report INCOMPLETE; reaching the specified depth reports only
PASS_WITHIN_DECLARED_DEPTH. Counts are observations, never acceptance targets.

Directed traces can use additional named cells and two owners; they are fixed
programs, not an assertion that the explored state space includes every trace.
The abstract Completion control deliberately uses non-owning payloads; the same
owning enum laws are tested by ArrayResult. Retirement booleans stand for separate
observed proof facts at this model boundary, not an implemented safe_to_free flag
or provider. Actual command/target/release provenance is owned by the unchanged
R3 model. No implicit async error drain/start behavior is simulated.

Limits: no grammar/exhaustiveness/name-resolution execution, generic definition
checker, physical layouts, real allocator/empty-buffer free behavior, full alias
analysis, foreign frames, asynchronous execution, native memory qualification or
universal soundness proof. Campaign-only documentation/protection validators and
report packagers are retired; the independent model and review regressions remain.

`review_regressions.py` ports the immutable baseline review scenarios into fixed
corrected-model traces. The checker derives selected binding values, complete
cells and event deltas from the pre-state schema/pattern. It checks scalar/record
snapshots as events and nested enums as exact cells. Coherent wrong-owner swaps
pass global accounting and fail this separate relation.

Loans carry their lexical extent and root/epoch/value witness. Error routes end
only crossed loans before owner cleanup; ordinary arm completion remains an
explicit checked loan end. Exact consumer IDs and parent IDs authorize aborts;
a handler continuation names the surviving pending consumer. Equal scope depths
do not identify consumers. Reservations belong to one consumer, commits deliver
its arguments once, and committed effects remain committed. Route refusals run
in a bounded temporary state and leave the original unchanged. Consumers/loans
are fixed directed domains, not an enlarged storage/call-stack explorer.

Historical model bytes and campaign qualifications are recoverable through Git
history. Current model runs do not grant compiler or platform qualification.
