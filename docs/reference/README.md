# The Astra Language Reference

The full normative Reference is planned for **28-A2**. The current checked API
documentation infrastructure is scoped to **28-A1**; these chapter destinations
are a versioned writing plan, not a claim that the book is complete.

The [chapter manifest](../chapters.json) maps planned grammar, evaluation,
ownership, effects, ABI, generics, matching, ranges and language profiles to
current compiler source and conformance tests. Follow [API documentation](../api/README.md)
for derived symbol contracts and [release exceptions](../release-exceptions.md)
for historical limits. Later print publishing will derive from authored Markdown.
