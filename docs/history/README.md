# Donor history

This foundation imports the committed source of `astra-bootstrap` at
`61d1529956369770fc817563a43b0038b852ab90`, with the layout-lifetime repair at
`88eca9e953ec418994ac5b4a2ee97db7d7a354bc` in its ancestry. The rename between
those revisions changed routing and documentation, not compiler semantics.

Historical files that remain in this tree describe the donor's measured profiles.
They do not qualify the relocated compiler. Raw receipts containing private host
paths and donor-local workflow files are retained outside Git in the independently
restored history archive identified by `bootstrap/provenance.json`. Reviewed public
documentation projections explicitly identify path omissions. Original records,
including failures, compiler fingerprints and prior milestone IDs, remain unchanged
in that archive and in the donor.

Historical frozen challenges require their original private receipts and exact
compiler/source/dependency identities. Current regression modes must not claim
historical challenge credit. API-B2 can run in current mode without a historical
freeze; an explicitly supplied freeze remains enforced.
