# M16 explicit foreign personalities

The declaration-driven profile accepts one common Class carrying C, COM and
GObject policies. Explicit `--foreign-personalities=c,gobject` selects the hosted
Linux surfaces; `--foreign-personalities=c,com` selects Windows x64. `none` keeps
the native Class and native calls while emitting no Class adapters or provider
references. A selected incompatible target rejects. Historical invocations keep
their automatic selection and bounded-profile admission.

The immutable API schema retains both the declared policies and the explicit
selection. Its full identity, equality and imported nominal identity include that
selection. Each detached compiler stage checks its own original identity; a
mutation test substitutes a valid but differently selected policy at Core, CFG,
SSA, native ABI and CABI and requires rejection. Inactive imported call targets
reject before lowering. Their retained declaration-only models lower to internal
unreachable stubs, so an unused COM declaration adds no provider link dependency
to the Linux product. Parse-only modes report the syntax inventory; later modes
report the checked inventory on stderr without contaminating generated files.

The common fixture executes native algorithms, a captured native Closure viewed
as a call-scoped callback, a checked error and a mutable property. Independently
declared C/GObject and C++/COM clients verify the same native state and exact root
retirement. The Linux recipe runs native-only O0/O1/O2 and five mixed native/bridge
optimization combinations, including memory checks without suppressions. The
Windows recipe produces the same five combinations for execution on the approved
existing win11 VM. Native Windows receipts check every executable hash, case exit
and assertion marker. Temporary CD media is restored; persistent configuration
and the running user session are preserved.

Modern Windows admission now includes synchronous nonthrowing native captured
Closures with copied scalar parameters/results and an admitted concrete native
environment. Legacy Windows closure admission remains as previously qualified.

The companion JSON records the exact compiler, sources, regression and VM
receipts. This is an intermediate prerequisite. Retained declaration-driven
signals, foreign metadata in opaque native units, the frozen second-API SDK
challenge and final complete G0–G9 qualification remain unfinished.
