# ADR 0092: Explicit native Linux timers sharing task ownership

**Direction:** USER_APPROVED L1-LINUX-URING-TIMERS in the ASYNC-IO-1 starter on 2026-10-08. The instruction selects Linux v7.2 and liburing 2.15 floors, explicitly authorizes the provider clause, LinuxExecutor, delay_ms/wait boundary and privately built pinned helper when needed. One cumulative 21,600-second campaign includes intake and handback. Completed A2 proceeds from a13ba32 with later user confirmation and reconciled supplemental receipts; its original partial records remain intact.

**Implementation:** one thin optional liburing-assisted provider shares the existing task scheduler and `native-tasks-v15` ownership/result/exception core. The supplemental provider capability is `linux-uring-timers-v1`. [Source operations](../platform/linux-uring-timers.md), [retirement boundary](../abi/linux-uring-timers.md) and finite validation define the delivered scope; exact final qualification belongs to the external handback receipts.

The selected ring is single-threaded, non-SQPOLL, SQ32/CQ64 with explicit CQSIZE|SINGLE_ISSUER|NO_SQARRAY and NODROP. IMMEDIATE_ARG removes user-memory timespec retention; application buffers still retain their source owners while suspended. Separate integer target/cancel IDs map to full task tokens. Neither a virtual timer-clear shortcut nor a cancel CQE substitutes for target observation. Source exceptions are delivered only after safe retirement; unrecoverable integrity loss has an explicit non-unwinding boundary.

Compared with a second scheduler, this seam preserves the already qualified ownership and root policy. Compared with handwritten UAPI mapping/barriers, the pinned helper reduces the maintenance surface while leaving credits, decoding and lifetime decisions in Astra. timerfd/epoll remains a possible later readiness direction; no automatic fallback or performance claim follows. Default compiler, virtual and nonasync builds retain their dependencies.

The [historical proposed Linux profile](../platform/linux-async-profile.md) and R3 contracts remain source-inspection records. Actual host qualification is separate: Linux 7.2.9-200.fc44.x86_64 and privately built liburing 2.15, with exact setup, expiry and cancellation receipts. Broad IO, threading, sharing and language extensions remain open. Seven roadmap tracks and Q01–Q35 are preserved; LAZY-1 is near-term and PERF-01 unscheduled. Work stops at this handback.
