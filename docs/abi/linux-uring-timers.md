# Private Linux timer boundary

The existing `native-tasks-v15` frame/result/exception ABI is preserved. The supplemental provider capability is `linux-uring-timers-v1`: detached native frame plans retain the immutable provider kind, and source/native correspondence rejects a separately valid plan for a different provider. LLVM bindings independently retain the exact provider call, task, checked sign/zero extension, resume PC and completion-status branch after predecessor graphs are released.

`linux.h` supplies `astra_async_linux_open(u32)`, `astra_async_linux_delay_ms(task,i64)`, `astra_async_linux_delay_result(task,u32 pc)` and `astra_async_linux_wait(executor)`. Admission returns 1 or 0; the resume-side result returns zero or positive errno. Generated code constructs the nominated ordinary AsyncError with stable timer/executor messages and the existing throw machinery. The internal `AstraAsyncLinuxFailure` retains stage, errno and operation ID, including distinct target/cancel stages. It is a single-threaded diagnostic boundary, not a public formatting or Task C ABI.

`provider.h` connects one scheduler to optional provider service/cancel/close functions. The core still owns task frames, ready state, descendants, tokens, publication, root rights and shutdown. Suspension retains the timer record as an external backing and captures the exact continuation PC. Completion validates the full executor/slot/generation token, PC, pending state and single retained backing before observed release and wake. A virtual timer-clear operation cannot clear Linux retention.

The provider owns one ring and sixteen bounded records. Each wait assigns two process-unique monotonically increasing nonwrapping operation IDs, a nonwrapping record generation, full task token, PC and checked immediate nanoseconds. Target and command identities are separate; no frame pointer or narrowed token is encoded into `user_data`. Exhaustion refuses admission before publication. Records can be reused only after all required completion evidence has been observed.

liburing prepares, maps, publishes and consumes the ring with its maintained ordering helpers. The timeout uses NULL timespec preparation followed by integer `sqe.addr=nanoseconds`, count=0 and IMMEDIATE_ARG; it never encodes a duration as a fake pointer. Cancel64 targets the timeout ID with flags=0 and its own command ID. At most sixteen targets and sixteen commands can be outstanding, below CQ=64. SQE acquisition reserves a persistent intent; helper publication or a short/negative enter result never permits reconstructing and duplicating that intent. SQ head consumption remains liburing's authority. The immediate argument exposes no application payload pointer to the kernel.

Monotonic local preparation ordinals associate each record with the helper's private flushed head and `io_uring_sq_ready` consumption observation. The record separately tracks prepared, SQ-exposed and kernel-consumed facts for target and command. CQ evidence independently confirms consumption. The decoder refuses evidence for an unpublished intent. No custom shared-memory barrier is added, and the reserved unique IDs bound ordinal exhaustion too.

The production decoder validates ID, role, flags and terminal result before changing evidence. Target `-ETIME` is expiry; authorized target `-ECANCELED` participates in cancellation. Cancel 0/ENOENT/EALREADY remains separate evidence. An observed cancel without its target cannot release retention. Conversely a target with an already prepared cancel waits for that command too. Other negative terminal errors are deferred until this retirement handshake permits source delivery. Positive/count-based results, MORE/NOTIF, duplicate/stale IDs and malformed results stop at the integrity boundary.

Permanent submission failure stops normal execution and attempts two safe nonwaiting prepare/submit/completion batches without user dispatch. If proof cannot support ordinary recovery, `_Exit(120)` is the documented fatal non-unwinding boundary: it never unwinds and frees unknown live frames. Malformed CQ evidence offers no safe authority to advance that entry or retire its target and stops immediately. Normal close requires zero active records and empty SQ/CQ, in addition to shared-core root/shutdown observation.

`ASTRA_ASYNC_LINUX_TEST_PROTOCOL` adds only qualifier controls: bounded fake SQ transport, injected submit results, held CQ consumption, production-decoder ingress, retained-record snapshots and exhaustion. It is absent from production archives. Injected errors/orders are not evidence that the kernel produced them. Native adapter bodies probe the seam; real source bodies, catches and ownership transfers are generated by the Astra compiler.
