# Current Astra language contract

The complete compiler is the Vala bootstrap in `bootstrap/`. The source/diagnostic
and lexer components in `compiler/` execute in Astra; later compiler stages remain
to be ported. The inherited `0.0.3`/RC2 banner is not a new release qualification.
The domain table below and the [structural generics](structural-generics.md),
[foreign APIs](declaration-driven-interop.md), [concurrency](concurrency.md) and
[optimizer proof](semantic-optimization.md) guides describe current contracts.
They do not declare the Founding Bible complete.

Runtime composition supports these domains, within each guide's explicit limits:

| Runtime domain | Current supported contract | Boundary |
| --- | --- | --- |
| [Allocator contexts](allocator-contexts.md) | Distinct same-type instances, owned backing leases, checked scoped backing, selected Classes/containers/closures/bytes and task frames | Exact lifetime effects and transitive thread capabilities; scoped and affine graphs do not gain arbitrary thread transfer. |
| [Executor composition](executor-composition.md) | Cooperative/Linux service awaits real worker results, errors and cancellation using task ABI 17; one process also performs real io_uring file I/O | Explicit worker submission, bounded admission and joined retirement; worker-to-service cycles remain refused. |
| [Numeric endpoints](network-endpoints.md) | IPv4/IPv6 address-bearing TCP/UDP with actual peer metadata, partial progress, deadlines and truncation | Linux nonblocking socket provider; numeric addresses; socket readiness and file io_uring remain distinct mechanisms. |
| [Native units](native-units.md) | Opaque ownership/runtime-facing libraries with versioned context and deferred task effects | Matching compiler fingerprint and current schema; changed interfaces require rebuilding consumers. |
| [Integrated products](../../examples/runtime-composition-17/README.md) | Astra streaming computation with bounded queues, selected backing, worker/network/file overlap and independent output oracle | Current regressions use independent application/peer oracles; historical M17 qualifications retain their original revisions. |


Historical Surge-3 and Surge-6 PARTIAL, strict LAZY-1 Q4 HELD/INCOMPLETE and the
original bounded ENUM-OWN-1 PARTIAL outcomes remain historical. Later scoped
acceptances do not rewrite them. Retired campaign reports and original limits are
recoverable through [Git history](../history/active-tree.md); current test runs
carry their own source, compiler and profile identities.

The complete bootstrap compiler is implemented in Vala/C with host GLib/GObject and LLVM dependencies
defined in [Meson](../../meson.build). These implementation-language facilities
are not Astra source features or mandatory dependencies of emitted programs.
Emitted programs acquire only selected library/platform/provider and allocation
dependencies; see [base-library component costs](../library/base.md),
[host-buffer allocation](../backend/host-buffer-allocation-v0.md) and
[native execution](../backend/native-execution-v0.md). No roadmap requirement
imposes GObject identity, GC, reference counting, heap allocation, threads,
reflection or an unwinder on every program.

Generated milestone/version labels are build configuration identifiers, not
proof of current language acceptance. The compiler remains version 0.0.3. Fresh
source, compiler, tool and product identities are recorded in the
ecosystem validation.

Historical full-suite records retain their original compiler/source identities:
M17 records 9,564 registrations; the earlier 9,099-test OWN-SWAP runs retain their
compiler-dependency limitation. Neither count supplies fresh M18 execution.
Current M18 test names, declared exits/protocols/dependencies, serial barriers,
application variants, foreign/installed profiles and failures/retries must close
against one final implementation before candidate qualification.
