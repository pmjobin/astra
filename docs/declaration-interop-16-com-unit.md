# M16 opaque Windows COM units

Explicit modern personality selection admits object-only Windows native units in
`windows-x64-llp64-foreign-units/4`. The target and data layout are pinned, and
objects must be bounded x64 COFF relocatables. Automatic historical Windows
invocations retain their existing native-unit refusal. Linux `/3` and `/4` units
retain their previous schemas and ELF checks.

The `/4` format now retains typed COM import declarations alongside native Class
declarations and objects. Foreign declarations grant their ordinary checked
foreign-wrapper authority; native implementation declarations grant external
native symbol authority. Each has an exact recorded origin. Import verifies the
complete normalized API, IID/slots/parent, factories and native bindings. Raw
foreign declaration text is covered by the receipt; its normalized contract is
covered by the native ABI identity, as with the existing native declaration text.
The loader admits one bodyless typed COM declaration per metadata group.

The portable recipe removes both producer and protocol source copies, generates
the SDK from metadata, then compiles independent C++ consumers. The native Astra
consumer exercises an opaque shared Class and imports an independent COM provider.
The C++ consumer uses an independently authored IID/slot oracle to call the native
Class's COM view. Five native/bridge optimization combinations check properties,
floating-point computation, checked errors, owned bytes and captured callbacks.
Assertions cover canonical IUnknown identity, shared native state, final native
and provider retirement, provider reference restoration and exact matching
CoTaskMemFree for imported bytes. Windows HeapValidate checks heap integrity;
this is not a Windows leak measurement.

Native win11 receipts bind every executable hash, assertion marker and exit.
The temporary read-only media is ejected afterward; persistent XML remains
identical to the initial inventory and the user session remains running.
Re-sealed declaration mutations independently test IID, error code, executable
body injection and callback signature authority. Target/schema and selection
drift also reject. The companion JSON records actual qualification and failures.

composition breadth and final complete G0–G9 qualification remain unfinished.
